# Symptom Matrix Analyzer

Python system to track symptom indicators against a JSON database.

## Running in GitHub Codespaces
1. Click the **Code** button on your repository page.
2. Select the **Codespaces** tab.
3. Click **Create codespace on main**.
4. In the terminal window at the bottom, type:
   ```bash
   python app.py
   ```

## Local Setup
```bash
python app.py
```
